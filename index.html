MobiusOS

complex yet simple.

A systemd-free Linux gaming distribution. No systemd anywhere in the stack — just OpenRC, eudev, elogind, and the tools that get out of your way so games can use the hardware they're running on.

See editions Follow progress on GitHub

Where things stand

MobiusOS is in pre-release. There are no downloadable ISOs yet — the project is still being built out. This site tracks what's planned; check the GitHub repo for actual progress.

The pre-release build uses an Artix Linux base, but package management is handled with Nix instead of Artix's default tooling.

Questions & answers

Q: What is systemd?

A: systemd is the first process that runs on your computer (after the kernel, of course). It is one of the most popular initialization systems (Process ID 1) and service managers, and is found in almost every GNU/Linux distribution these days. Why?

  • Parallel booting
  • Dependency resolution (automatically figures out what services need each other)
  • Built-in logging (with journald)
  • Advanced resource management

etc.

Q: What's OpenRC?

A: OpenRC is a dependency-based initialization system and service manager. It manages system startup, shutdown, and the background services (daemons) that run while your computer is on. It's most famously used as the default init system for Gentoo Linux and Alpine Linux. It is also one of the most popular alternatives to systemd. Why?

  • Modular architecture (it remains strictly an init system and delegates tasks like logging and networking to specialized, separate tools)
  • Reduced bloat (avoids taking over core system functions)
  • Simpler configuration (uses straightforward shell scripts)
  • Faster boot times (on servers or systems with large numbers of virtual devices or very few services)

etc.

Q: What do gaming and systemd have to do with each other?

A: Nothing much. Steam doesn't care if you have systemd or not. Nor does Proton, Lutris, or KDE.

Q: Why are you using OpenRC then?

A: Because everyone is on systemd. I wanna prove that systemd isn't some Linux gaming prerequisite. OpenRC shows that you can have a clean, modular system and still suck at Team Fortress 2.
