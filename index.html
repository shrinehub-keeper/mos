MobiusOS

complex yet simple.

A systemd-free Linux gaming distribution. No systemd anywhere in the stack — just OpenRC, eudev, elogind, and the tools that get out of your way so games can use the hardware they're running on.

See editions Follow progress on GitHub

Where things stand

MobiusOS is in pre-release. There are no downloadable ISOs yet — the project is still being built out. This site tracks what's planned; check the GitHub repo for actual progress.

The pre-release build uses an Artix Linux base, but package management is handled with Nix instead of Artix's default tooling.

Why no systemd?

MobiusOS swaps systemd out for a leaner init and service stack: OpenRC for init, eudev for device management, elogind for session/seat handling, fcron for scheduled tasks, and syslog-ng for logging. Fewer daemons competing for attention on a gaming rig, and a service layer you can actually read and edit as plain shell scripts.

Editions

Three builds, depending on what you're running MobiusOS on.

Legacy

Pre-UEFI · pre-2012

Recommended for pre-UEFI systems (roughly before 2012) and/or hardware that can't handle a modern desktop environment.

Main

UEFI · 2012+

Recommended for UEFI systems (2012 onward) and/or hardware that can comfortably run a modern desktop environment.

Deck

Handheld

The Main edition, tuned for Steam Deck.
