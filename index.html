MobiusOS

complex yet simple.

A systemd-free Linux gaming distribution. No systemd anywhere in the stack — just dinit, eudev, elogind, and the tools that get out of your way so games can use the hardware they're running on.

See editions Follow progress on GitHub

Where things stand

MobiusOS is in pre-release. There are no downloadable ISOs yet — the project is still being built out. This site tracks what's planned; check the GitHub repo for actual progress.

The pre-release build uses an Artix Linux base with Arch's extra repositories — think of it as the GhostBSD of Artix.

Questions & answers

Q: What is systemd?

A: systemd is the first process that runs on your computer (after the kernel, of course). It is one of the most popular initialization systems (Process ID 1) and service managers, and is found in almost every GNU/Linux distribution these days. Why?

  • Parallel booting
  • Dependency resolution (automatically figures out what services need each other)
  • Built-in logging (with journald)
  • Advanced resource management

etc.

Q: What's dinit?

A: dinit is a service manager / supervision system, which can (on Linux) also function as a system manager and init. It can be found in Chimera Linux, eweOS, etc. It is:

  • Portable — written in portable C++ code; compiles and runs on a variety of Unix-likes (Linux, various BSDs)
  • Compact — with a reasonable feature set, but a sufficiently limited scope; designed to work with other system components, rather than replace them
  • Robust — written with a focus on being secure and correct
  • Usable — with simple configuration syntax and control commands
  • Well documented — check the extensive manual pages!
  • Free and Open Source — distributed under the Apache License version 2.0

Q: What do gaming and systemd have to do with each other?

A: Nothing much. Steam doesn't care if you have systemd or not. Nor does Proton, Lutris, or KDE (well KDE might have a systemd-only future so eh).

Q: Why are you using dinit then?

A: Because everyone is on systemd, and its bloated af. I wanna prove that systemd isn't some Linux gaming prerequisite. dinit shows that you can have a clean, modular system and still suck at Team Fortress 2.
